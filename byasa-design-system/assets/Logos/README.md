# Logotipos principales de BYASA

Colores oficiales del logotipo: rojo #C73039 y gris #8B8E92. Versiones recoloreadas al rojo oficial desde los originales, que usaban #EF5047.

- `byasa-logo-horizontal`: ícono, separador y logotipo con lema, en rojo y gris. Versión principal para fondo claro.
- `byasa-icon`: solo el ícono.
- `byasa-favicon`: ícono en lienzo cuadrado, para favicon.
- `byasa-logo-horizontal-fondo-oscuro`: ícono rojo con logotipo y lema en blanco; usar sobre fondos oscuros.
- `byasa-logo-horizontal-blanco` (All White): usar solo cuando el logotipo no se puede integrar de la mejor manera. Versión tal como se recibió, ícono solo con contorno fino; no se recoloreó.

Espacio libre: 40 px por lado. Ancho mínimo: 100 px. Fondo transparente.
